# Stock BigBox Hybrid fan shroud (from E3D's Hybrid v1.1.0 STEP)

Extracted from `Hybrid_v1.1.0..stp` (E3D's printed-parts list for the Hybrid), exported in the installed orientation (Z up, blower end at the top, outlet foot at the bottom), millimetres, origin at the part's corner.

- `stock_fan_shroud_plain.stl/.step` - 50.5 x 60.5 x 63.0 mm, 13.0 cm3. The arched duct: a tilted inlet at the top (two prongs about 37 mm apart for the 40 mm blower), a tube that arches around both sides, and the outlet box with the scoop at the bottom. **Best match for the "semicircular duct".**
- `stock_fan_shroud_with_bridge_bar.stl/.step` - the same duct with a curved cross bar merged in (53.0 x 60.5 x 68.4 mm, 15.3 cm3), as laid out in the parts list.
- `stock_fan_bridge_bar_maybe.stl/.step` - the bar on its own (12.4 x 42.6 x 20.1 mm). Role (blower retaining bridge) not verified.

Not verified: that this is the exact part on the printer; compare with the physical duct (prong spacing, bar or no bar) before printing. The part-list file has no part names, so the identification is from shape and from the E3D manual's description of the fan assembly (blower, M3x22 plus 2 x M3x30 screws, fan moves on slots in the carriage).

Print notes: needs supports as exported (the tube arches up from the foot); best in ASA/ABS/PC or at least PETG near the heater block; leave the outlet and tube unblocked. Original design (c) E3D; licence not checked.
